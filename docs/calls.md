# Звонки: как звонит iOS и что нужно Android

**Зачем.** В Android звонков нет: кнопки «Позвонить» и «Видеозвонок» отвечают «пока нет» (`PeerInfo.kt` 238-239), а звонок
с айфона Android не слышит. Звонки Android повторяют iOS (правило Анны: всё копируем с iOS). Эта страница — карта iOS по
файлу и строке: что говорят друг другу телефоны, по каким дорогам, и что из этого берёт Android.

**Откуда.** Код iOS, рабочая линия `rollback-898` дерева Montana-iOS, строки на 06.10.2026. План Анны с 06.10 — в
`timechain/HANDOVER.md`.

---

## 1. Движок

- iOS: `WebRTC.xcframework` от webrtc-sdk, версия **144.7559.10** (`fetch-webrtc.sh`), и CallKit — системный экран звонка.
  Весь звонок — `MontanaCall.swift` (7438 строк).
- Голос и видео идут шифром DTLS-SRTP самого WebRTC. Свой слой поверх (SFrame) **выключен**: `myCaps()` говорит
  `sframe: false` (`MontanaCall.swift` 902-909). Android его тоже не включает — так звонок с айфоном совместим.
- Классическое рукопожатие DTLS — пропуск по стандарту, не наша защита: сигнал звонка и его ключ идут постквантовой трубой
  (`MontanaCall.swift` 6-16, [I-16] A-4).

## 2. Имя и жизнь звонка

- Семя звонка — 32 случайных байта (`MontanaCall.swift` 1766), в сигнале — base64 в поле `s`.
- Эпоха звонка — первые 16 знаков base64 семени (`callEpoch`, 4213). Каждое слово несёт её в `e`; слово чужой эпохи
  хоронится (`MontanaE2E.swift` 1139-1148).
- Жизнь звонка — **90 секунд** (`callLifeS`, 4218): столько звонит звонящий, предложение старше 90 секунд не звонит.

## 3. Слова сигнала

Сигнал — JSON-массив объектов `CallSigMsg` (`MontanaE2E.swift` 1283-1302):

| поле | что |
|---|---|
| `t` | всегда `"cal"` |
| `ctrl` | слово (таблица ниже) |
| `sdp` | `{type, sdp}` — предложение или ответ |
| `candidate` | `{candidate, sdpMid, sdpMLineIndex}` — один адрес; пачка — каждый адрес своим объектом (1090-1091) |
| `video` | видеозвонок |
| `caps` | `{tier, ver, opus_max, hw_aec, sframe, av, rejoin}`; iOS: `ios-native`, 1, 64000, true, false, true, true |
| `ts` | момент по часам узла, мс |
| `rsn` | для `call-restart`: `ice` или `media`; для `call`: `rejoin` |
| `n` | имя звонящего — только в `call` |
| `s` | семя — только в `call` и `call-gone` |
| `e` | эпоха |

| слово | смысл | где в iOS |
|---|---|---|
| `call` | вызов; с `sdp` — предложение, повтор каждые 2 с (до 6 раз) до «звонит» или ответа | 1881-1919 |
| `call-ringing` | «у меня звонит» | 2218 |
| `call-answer` | ответ (`sdp` answer) | 2736 |
| `call-ice` | адрес-кандидат | 4946 |
| `call-end` | отбой | 487, 2185 и др. |
| `call-gone` | звонок потерян этим телефоном | `MontanaWakePush.swift` 3377 |
| `call-hold` / `call-resume` | удержание | 347, 385 |
| `call-video-ask` / `-ok` / `-no` / `-end` | видео посреди звонка | 3145-3221 |
| `call-screen-on` / `-off` | показ экрана | 3316, 3333 |
| `call-restart` / `call-restart-answer` | пересогласование | 5162, 2416 |
| `call-key` / `call-key-ok` | ключ SFrame (выключен) | 2380-2389 |

Android сперва: `call`, `call-ringing`, `call-answer`, `call-ice`, `call-end`. Остальное — после.

## 4. Дороги вызова

Айфон зовёт сразу по всем (`MontanaCall.swift` 1779-1829, `MontanaE2E.swift` 1084-1230):

1. **Живая труба телефон-телефон** — `\u2063mtcall:` + base64 JSON (`ContentView.swift` 3485). У Android живой трубы нет
   (паритет, раздел 13) — эта дорога ему пока не нужна.
2. **Дорожка узла** — тело `мой адрес ‖ 0 ‖ эпоха ‖ 0 ‖ zlib(JSON)` под ключом трубы, `POST /signal {conv, from_id, env}`,
   приём — долгий вопрос `/signal-fetch` (`MontanaWakePush.swift` 2951-3006, 3034-3090). Android уже ходит по ней за
   «печатает…» (`Presence.kt` 37-83), но берёт только эпоху `chat` (`Presence.kt` 60) и только пока открыт чат
   (`Conversation.kt` 728).
3. **Звонок-письмо** — `\u200B\u200BRG:` + `{v, s, n, t}`, тихое, одно на звонок (`MontanaE2E.swift` 1212-1225); через
   10 секунд без «звонит» — громкое `{…, b: 1}` (1173-1181, 1816-1819). Android читает ящик каждые 8 секунд, пока открыт
   (`MainActivity.kt` 176-184), но все служебные слова без своей ветки молча хоронит (`Pipes.kt` 140, 687).

Ещё «стук» через Apple (`ringReach` → `wakeVoip`) — только для айфона. Android на него не записан: айфон слышит «некому»
и стук прекращает (`MontanaCall.swift` 1799-1801).

## 5. Пропущенный звонок и строка звонка

- Письмо «пропущенный» — `\u200B\u200BMC:` + `{v, s}` (`ContentView.swift` 3790, `MontanaMissedCall.swift` 51-55). Android
  его хоронит (`Pipes.kt` 687).
- Строку звонка в чате каждый телефон пишет сам, у себя: `{v, inc, dur, miss}` (`appendCallLog`, `MontanaChatStore.swift`
  2544-2570); одна строка на звонок. Монета за секунду звонка (2564-2566) — у Android кошелька нет.

## 6. Ретранслятор

- Пропуск: `POST /turn-cred` с `{}` → `{username, credential, uris, stun}` у всех дверей сразу, первый ответ берётся
  (`MontanaWakePush.swift` 1467-1495). Пропуск помнится и живёт часы.
- Настройка соединения (`MontanaCall.swift` 1028-1111): unified plan, сбор адресов непрерывно, один общий канал, обе
  дороги — прямая и через ретранслятор; серверы: STUN, затем TURN, `turns:` на 443 первым.
- Звук (`tuneSDP`, 1632-1637): к `useinbandfec=1` добавляется `stereo=0;maxaveragebitrate=64000;maxplaybackrate=48000;cbr=0`.

## 7. Как звонит айфон

Семя → «исходящий» → стук каждые 5 с до «звонит» → соединение → предложение → `call` с `sdp` по дорогам → повтор каждые
2 с → `call-ringing` от вызываемого → `call-answer` → адреса `call-ice` → разговор → `call-end`. Не соединились за 90 секунд —
отбой.

## 8. Как будет принимать Android

`RG:` в ящике (до 8 секунд) → экран «Входящий звонок» с именем `n` и дорожка узла этого чата слушает эпоху звонка →
`call` с `sdp` → ответить `call-ringing` → «Ответить» → ответ `call-answer` → адреса → разговор. Отбой — `call-end`.
Не ответил — айфон пришлёт `MC:` → строка «Пропущенный звонок».

Правила iOS, которые Android повторяет (`MontanaCall.swift` 2094-2240): своё семя, вернувшееся назад, — ничего; копия того же
семени — ничего; предложение старше 90 секунд — `call-end` с эпохой этого звонка; оба нажали «позвонить» разом — живёт
звонок с меньшим семенем, второй тихо сворачивается.

## 9. Шаги Android (план Анны)

1. Эта карта.
2. Движок WebRTC в сборку (`scripts/build.py` без Gradle: `classes.jar` в Kotlin и d8, `libjingle_peerconnection_so.so`
   arm64 в `lib/arm64-v8a`); источник — тот же webrtc-sdk, линия 144.7559, после «да» Анны.
3. Android слышит звонок айфона: `RG:` → «Входящий звонок», `MC:` → «Пропущенный звонок».
4. Голосовой звонок в обе стороны.
5. Видеозвонок.
