# Audit reports

The [13-item protocol review](Protocol-13/README.md) records the current closure work on finality,
issuance, authenticated joining and node privacy. Its status is **open**. This directory is a
separate, public entry point; it does not certify the protocol or a released application.

The repository-wide [audit package](../AUDIT.md) describes the published source snapshots and
other open findings. Older reports are historical evidence at their stated source revisions;
their test counts and readiness statements are not results for a later revision.

Reports distinguish implementation, a reproduced counterexample, a regression check, and a
complete acceptance result. Passing a test that reproduces an exploit is evidence of an open
defect. A run by the implementer on a separate server is self-verification, not an independent
external audit.
