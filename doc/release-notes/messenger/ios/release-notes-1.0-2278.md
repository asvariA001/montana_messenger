1.0 (2278) Release Notes
========================

Montana for iPhone, iPad and Mac, build 1.0 (2278), from source commit `31b8b4e0afe4dc658629a32f1d7fd600a3d1d0a0` of 2026-10-22. The folder `apps/messenger/ios` of this repository holds that tree as it is built.

Notable changes
---------------

- Montana Core for Mac now rebuilds byte for byte from the public source in montana_core: any builder, at any path, gets the same app, and the release names its digest.

Security and anonymity
----------------------

- Only how the Mac app is built changes; nothing new is stored or sent.
