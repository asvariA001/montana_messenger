1.0 (2255) Release Notes
========================

Montana for iPhone, iPad and Mac, build 1.0 (2255), from source commit `a27409a882ce2990de5536d23140c26ef47cad84` of 2026-10-20. The folder `apps/messenger/ios` of this repository holds that tree as it is built.

Notable changes
---------------

- Photos, videos and files in chats now lie on every Montana machine at once, so they arrive even when one machine cannot be reached.
