1.0 (2256) Release Notes
========================

Montana for iPhone, iPad and Mac, build 1.0 (2256), from source commit `9e2bf95036ca0dda3b3bb9c7737f31c117639d56` of 2026-10-20. The folder `apps/messenger/ios` of this repository holds that tree as it is built.

Notable changes
---------------

- Call recording follows levels: when your correspondent has recording turned off, it stays off unless your Global level is higher.
- A call recording now reaches the chat whoever made it.
