1.0 (2252) Release Notes
========================

Montana for iPhone, iPad and Mac, build 1.0 (2252), from source commit `52203d7b0e8e78d16914856ff342a688669b76d1` of 2026-10-19. The folder `apps/messenger/ios` of this repository holds that tree as it is built.

Notable changes
---------------

- Montana Core v1.0: from 20 October a second of life mints one coin, and the nodes take no more from any build.
- A build older than the one the network admits sees the update page at every opening, with the link to the new build.
