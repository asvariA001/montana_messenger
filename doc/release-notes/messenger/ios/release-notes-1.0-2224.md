1.0 (2224) Release Notes
========================

Montana for iPhone, iPad and Mac, build 1.0 (2224), from source commit `14b2fe341c23c489cbc91ec2b6b60df62d7586dd` of 2026-10-16. The folder `apps/messenger/ios` of this repository holds that tree as it is built.

Notable changes
---------------

- A group's title now says how many people are in it and, when someone besides you is here, how many of them are online. Only the people your phone already sees online are counted; a channel shows its count alone.
