1.0 (2215) Release Notes
========================

Montana for iPhone, iPad and Mac, build 1.0 (2215), from source commit `0897094575fe8ff4375167ca1ec09b941ffd1499` of 2026-10-16. The folder `apps/messenger/ios` of this repository holds that tree as it is built.

Notable changes
---------------

- Diagnostics: the notification extension now records how much processor time each incoming notification costs the phone, so the cost of a busy chat can be measured.
