1.0 (2279) Release Notes
========================

Montana for iPhone, iPad and Mac, build 1.0 (2279), from source commit `703f5d4aa69f39139258c80e043a6de459cf404a` of 2026-10-22. The folder `apps/messenger/ios` of this repository holds that tree as it is built.

Notable changes
---------------

- Montana Core for Mac is published with its install file: the notarized ZIP on GitHub and on the site, with its SHA-256, and a clean clone of montana_core rebuilds it byte for byte.

Security and anonymity
----------------------

- Only how the Mac app is built and published changes; nothing new is stored or sent.
